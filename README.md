# ai_usage
Artificial intelligence helped me a lot during the design process of my project. I mainly used it to better organize my Bootstrap and CSS styles, and to find cleaner and more visually balanced ways to present elements on the screen. Many times I had an idea of how I wanted something to look, but I wasn’t sure about the best way to implement it in code — that’s where AI became really helpful.

It also helped me adjust the images within the containers, since some of them looked stretched or didn’t fit properly with the card sizes. Thanks to that, I learned how to use properties that made the layout more responsive and visually consistent.

Overall, AI helped me refine the design, keep a more uniform aesthetic, and fix small visual details that made the page look more professional. More than just correcting errors, it helped me understand how to combine structure and style to achieve a more attractive and functional look.
